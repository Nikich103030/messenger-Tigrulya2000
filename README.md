# Tigrulya2000 - Чат в стиле 2000-х

Простое веб-приложение для общения в стиле ретро-интернета: регистрация, авторизация, общий чат, личные сообщения, друзья и профиль пользователя. Должен работать на Internet explorer 5.5+

## Описание

Проект представляет собой мини-мессенджер с веб-интерфейсом, похожим на старые сайты 2000-х. Он работает на Node.js с использованием Express и SQLite.

## Возможности

- Регистрация и вход в систему
- Общий чат
- Личные сообщения
- Список друзей
- Профиль пользователя
- Настройки и тема интерфейса
- Хранение данных в локальной SQLite-базе

## Технологии

- Node.js
- Express
- better-sqlite3
- HTML, CSS, JavaScript

## Требования

- Node.js 22+
- npm

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Nikich103030/messenger-Tigrulya2000.git
   cd messenger-Tigrulya2000
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

## Запуск

Запустите сервер:

```bash
npm start
```

Откройте браузер и перейдите по адресу:

```text
http://localhost:3000
```
